# 1:1 페르소나 코칭 시뮬레이터

팀장 교육을 위한 브라우저 기반 코칭 대화 연습용 프로토타입입니다.

## 실행
- [index.html](./index.html)을 다운로드한 뒤 브라우저로 열어 사용합니다.
- GitHub에 소스가 올라간 것만으로 공개 웹사이트가 자동 배포되지는 않습니다.

## 포함된 기능
- 구성원 페르소나와 면담 상황 설정
- 스마트폰 메시지 형식의 코칭 대화
- 코칭 평가: 종합 점수, 세부 점수 막대그래프, 잘한 점, 개선점, 다음 코칭 팁
- 대화 기록 다운로드
- 브라우저용 AI 연결 설정(개인 실험용)

## 중요한 제한
- AI 미연결 시 구성원 응답과 평가 결과는 규칙/키워드 기반의 **교육 시연용**입니다. 실제 코칭 역량을 검증한 심리측정 도구가 아닙니다.
- 브라우저에서 API 키를 입력하는 방식은 교육생에게 배포하거나 다수의 팀장이 동시에 사용하는 운영 환경에 적합하지 않습니다. 실제 교육용 운영에는 API 키를 숨기는 서버, 이용자별 세션 분리, 데이터 저장/보안 관리가 필요합니다.
- 실제 AI를 통한 대화 및 평가 기능은 API 연결 및 테스트가 필요하며, 현재 코드는 완성된 다중 사용자 서비스가 아닙니다.
- 실제 직원의 개인정보나 민감한 인사정보를 입력하지 말고 가상 페르소나를 사용하세요.

## 이후 확장 방향
- 서버 API 연동 및 보안
- 교육 차수, 개별 교육생 세션, 관리자 대시보드
- 평가 이력 저장과 보고서/엑셀 다운로드
